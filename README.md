# تحلیل داده‌های نقد آمازون — فاز اول

**پژوهشگر:** نیما ادیبی معتمد  
**داده:** Amazon Reviews’23؛ چهار دستهٔ `All_Beauty`، `Appliances`، `Beauty_and_Personal_Care` و `Electronics`.

این مخزن کد و شواهد فاز اول پژوهش را ارائه می‌کند. مسئلهٔ اصلی، ارزیابی ارزش افزودهٔ متن پنج نقد معتبر نخست برای پیش‌بینی سهم نقدهای یک و دو ستاره در ده نقد معتبر آیندهٔ هر محصول است؛ آموزش و مقایسهٔ مدل‌های پیش‌بینی در فاز اول انجام نشده است.

## بازتولید

داده‌های خام را از [صفحهٔ رسمی](https://amazon-reviews-2023.github.io/) تهیه کنید و مطابق `data/README.md` در مسیرهای تعیین‌شده قرار دهید. در ویندوز، `CHECK_EDA_PHASE1_INPUTS.cmd` برای کنترل اولیه و `RUN_EDA_PHASE1_ALL_CATEGORIES.cmd` برای اجرا استفاده می‌شود. اجرای کامل روی دادهٔ حجیم ممکن است زمان و فضای موقت زیادی مصرف کند. کد نسخهٔ مرجع با مشخصات اجرا در مانیفست‌ها قابل پیگیری است.

**مرزهای انتشار:** دادهٔ خام و پایگاه‌های موقت در GitHub قرار نمی‌گیرند. فایل‌های گزارش و شواهد تجمیعی از دادهٔ خام جدا نگهداری می‌شوند. نسخهٔ کم‌فایل برای آپلود در سایت GitHub انتخاب شده و جزئیات کامل در آرشیوهای رسمی هر ممیزی نگهداری شده‌اند.

## نسخهٔ تحویل

پس از استخراج محتوای بسته در پوشهٔ ریشهٔ مخزن و کنترل فایل‌ها، تغییرات با Git ثبت و ارسال می‌شوند؛ اگر تگ `phase-1` پیش از آخرین commit ساخته شده، باید بررسی و به commit نهایی اشاره داده شود؛ ایجاد یک commit تازه به‌تنهایی تگ را جابه‌جا نمی‌کند. تنها آپلود ZIP به GitHub جایگزین ایجاد برچسب نیست. دستورالعمل سامانهٔ CW باید با آخرین اطلاعیهٔ رسمی بررسی شود.
